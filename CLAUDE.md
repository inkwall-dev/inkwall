# Instructions for Claude

Follow [CONTRIBUTING.md](CONTRIBUTING.md), in particular its commit and pull request rules. These matter most:

- Never add AI or tool attribution to commit messages, PR descriptions or issues: no
  `Co-Authored-By: Claude` trailer and no "Generated with Claude Code" line.
- Never commit or push without the maintainer's review. Leave changes uncommitted and summarize them;
  commit, push or force-push only when explicitly asked for that change.
- Every pull request needs an issue. Create the issue first with a label (`enhancement`, `bug`,
  `documentation`, ...), then start the PR description with `Closes #<issue>`. Check that the PR
  doesn't already exist before opening one.
